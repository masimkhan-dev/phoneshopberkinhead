# Agent Directives: Phone Shop Birkenhead

## Frontend Design & Engineering Standards

This project has **Taste Skill** installed to prevent generic "AI slop" and ensure authentic high-street retail design quality.

### Installed Skills in `.agents/skills/`:
- **`design-taste-frontend`**: Core Taste Skill v2 framework.
  - §0 Brief Inference: Reads page kind, audience, tone, and density before writing CSS.
  - Anti-Default Discipline: Bans AI-purple gradients, generic 3-card feature grids with lucide icons, identical section padding, and weak contrast.
  - Optical rhythm, bespoke layout families, and viewport stability.
- **`redesign-existing-projects`**: Audit-first protocol. Upgrades aesthetics, readability, and conversion paths without breaking frozen business logic, database schemas, or API contracts.
- **`high-end-visual-design`**: Soft/expensive visual feel, refined micro-interactions, deliberate typography scale, and premium surfaces.
- **`full-output-enforcement`**: Bans placeholders, unfinished sections, or skipped components.
